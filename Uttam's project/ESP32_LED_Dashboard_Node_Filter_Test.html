Active nodes

Enter an ID or inclusive range, such as 5 or 10-15. Separate multiple entries with commas. Only active nodes can be targeted. Leave blank to use all 60. A selection change stops pending simulation steps. Live commands already queued on the ESP32 continue.

Timed action

Maximum delay and pulse duration: 120 seconds each.

Number range · running lights

Turn LEDs ON in numeric order, from the starting node through the ending node. Delay is the time between successive LEDs. Both endpoints must be active. Only active nodes between them are used. Previous LEDs stay ON until you turn them OFF.

Programmed sequence

One step per line: time_s,target,mode,duration_s. Use seconds, including decimals. Target: all active nodes or one active ID. Live mode allows 32 steps after targets are expanded.

Activity

Command Status is a simulation, not confirmation of physical LED operation. Live Status requires an ESP32 master and recent slave reports. Keep the master Wi-Fi network private. Test all loads with suitable LED drivers, MOSFETs, fuses, and cooling.
